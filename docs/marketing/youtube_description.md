🎮 GAMES
Pac-Man • Ms. Pac-Man • Galaga • Donkey Kong • Donkey Kong Jr. • Frogger • Dig Dug • Xevious • Space Invaders • Super Cobra • Scramble • Pooyan • Time Pilot

🔧 WHAT YOU NEED TO BUILD ONE
• Raspberry Pi Pico 2 (RP2350)
• 240×320 SPI color display (ST7789 or ILI9341, 2.0"–2.8")
• Joystick or 4 direction switches + Fire, Start, Coin and Menu buttons
• Small amplifier and speaker
Every button is a switch to ground — no resistors. Pins are set in a text file on the Pico's USB drive. Full wiring diagram and step-by-step guide on GitHub.

✨ FEATURES
• Full 60 fps with sound on the RP2350
• Plays the original MAME ROM zips — checked automatically, with a clear message if a file is wrong
• High scores saved across power cycles
• Portrait or landscape display
• Two-button games (Xevious, Super Cobra, Scramble) with separate fire and bomb

🙏 CREDITS
Pico2Arcade is a port of Till Harbaum's Galagino (https://github.com/harbaum/galagino) with games from GalaginoPlus by VirtualClaudioBoy (https://github.com/VirtualClaudioBoy/GalaginoPlus), using superzazu's Z80 CPU core. Released under GPLv3.

⚠️ ROMs are not included. Use ROM sets you are entitled to use.
